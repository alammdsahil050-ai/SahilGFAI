# Sahil GF AI (Android)

1. Android Studio (Koala+) me folder open karo → Gradle sync.
2. Run on a real phone (Android 8+).
3. App → More → Gemini API Key → key paste karo (aistudio.google.com) → Save.
4. More → Permissions → sab Allow karo (Accessibility zaroori hai phone control ke liye).
5. Mic button tap karo → baat shuru.

Default model: gemini-3.1-flash-live-preview (More → Gemini API Key me badal sakte ho).
Memory: files/memory.txt, max 30 MB, purani lines auto-delete.
Notes: always-on streaming me API cost lagta hai; Play Store par Accessibility + always-listening ke strict rules hain (sideload/APK ke liye theek).
